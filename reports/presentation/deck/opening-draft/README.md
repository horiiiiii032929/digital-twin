`output/playwright/post-report-demo-final/03-consent-b1.png`; no new AI conversation
was generated for this draft. The UML uses standard activity partitions,
rounded actions, an explicit merge and guarded decision, and an activity final.

review walkthrough. Review is available without approving every message; the
activity final does not mark the learning goal complete. Later execution,
withdrawal and no-response cases belong in the later detailed slides.

as requested; edit the original to revise the diagram. The requirements table and
slide text are native editable PowerPoint elements. Notes contain source and scope
information, not the final spoken script.

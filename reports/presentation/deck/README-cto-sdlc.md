# Course Digital Twin — CTO / SDLC presentation

Current English deck, 8 September 2026. 31 main slides, six chapters, no appendix.
The narrative introduces the software, shows its current design, explains tested
alternatives and failures, and ends with current best choices and continued development.

- `digital-twin-presentation-cto-sdlc.pptx`: editable text, tables and charts;
  the unchanged 4:06 demonstration is embedded on slide 4 (click the video).
- `digital-twin-presentation-cto-sdlc.pdf`: static review copy; slide 4 is a poster.
- `digital-twin-30-day-demo.mp4`: separate copy for full-window playback.
- `diagrams/`: draw.io originals and the PNGs used by this deck.

BKT, PFA, MSE, Brier, BM25 and the local planner labels are explained where used.
The final slides distinguish retained implementations, promising unintegrated
candidates and proposed work. Source references are in the PowerPoint notes.
No new read-aloud script is included.

The talk is intended for roughly 30–35 minutes including the video; timing has
not been measured with a new English rehearsal. Native PowerPoint video playback
has not been exercised locally; embedded media identity and package relationships
were checked. The PDF has no playable video.

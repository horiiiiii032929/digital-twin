# Graduate CS review: applied changes

This note records how the graduate review informed `digital-twin-presentation-graduate-final.pptx`. It describes presentation changes, not newly established research results.

| Review concern | Applied response |
| --- | --- |
| Contribution was implicit | Main slide 3 states the system deliverable and empirical contribution; slide 32 returns to the same bounded findings. |
| Experimental interfaces were hard to locate | Main slide 8 shows standard UML component dependencies. The detailed container and lifecycle views remain in backup. |
| Planner effect lacked uncertainty and measurement context | Main slide 18 includes the paired effect, interval, action metrics and historical cost. Backup 44 distinguishes the runtime heuristic from the separate synthetic evaluation instrument. |
| Simulator assumptions and baseline fairness were easy to miss | Main slide 20 names the two authored families and the non-fitted, non-decaying count baseline. Backup 45 discusses stronger controls and PFA's next-answer result. |
| Factual score lacked denominators and instrument caveats | Main slide 14 shows 800 answerable and 200 boundary cases, 506/800 grounded and 192/200 boundary results, the grounded interval and scorer/question limitations. |
| Completion correctness could sound like validated mastery | Main slide 26 separates objective-scope compliance from assessment/mastery validity. Backup 46 defines the confidence field and the threshold limitations. |
| Online delivery needs current notes and reading time | Main talk stays at 32 slides. Notes include pointing and pause cues; Q&A references follow the new order. |

Remaining research gaps are explicit rather than claimed solved: real-student benefit, instructor fidelity, factual acceptance, assessment validity, a stronger learner baseline, an independent simulator family and the direct-analytic planner ablation. No new evaluation ran. Native PowerPoint video playback and a timed spoken rehearsal remain separate checks.

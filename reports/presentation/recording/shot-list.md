## Retake boundaries

For clips 02–04, restart the workspace and use the actual UI from a fresh session.
For clips 05–06, a fresh workspace plus `prepare_recording_checkpoint --published`
avoids repeating earlier setup off-camera. Treat this as a new take: course,
source and release lineage must match within the final sequence. Close/reopen
the relevant actor tab if cached state is stale.

At the end of each take note the actor, course, release ID, filename and whether
it is product UI or service replay. Keep this production note outside the video.
Record a readable result for at least three seconds. Add cut/speed-up indications
where processing time is compressed; never imply instant asynchronous processing.

## Before recording

- Correct actor URL, file and course; no unrelated tab or previous conversation.
- English input mode; copy ready outside the capture area.
- Wide browser window; inspector and action buttons fully inside the crop.
- Fixed crop, no notifications, no microphone for silent clips.
- Start status correct; no leftover error toast or spinner.
- Five-second sample watched before committing to longer takes.

## Before editing

- Verify the full answer and source locator are readable in the exported frame.
- Match each caption to the actual state; pending is not cancelled.
- Use synthetic observer labels on four-session overview, not professor analytics.
- Keep aggregate analytics hidden below the existing five-learner threshold.
- Describe the baseline as software behaviour, not learning improvement or model quality.

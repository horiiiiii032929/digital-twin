# Independent review packet after the quality audit

Prepared, **not reviewed or approved**. This packet replaces no historical score
and is not a held-out evaluation. No invitation or message has been sent.

-22 responses form11 matched cases, one per public question category (25% of44
existing development case labels). Both arms are included; course contexts are
balanced3/3/3/2. Selection is post-run, seeded620918 and uses public kind/course
only, not response scores or judge outputs. It is stratified coverage, not an
unbiased estimate of quality or the fresh400/200/200 confirmation.
-Share only this README, [packet](review-packet.md) and [blank template](reviewer-template.csv)
with an independent reviewer. Keep `allocation-key.json` separate until ratings
are complete; blinding hides labels, not possible stylistic clues in the text.
-No model judgments or prior gold are included. Review actual questions, prior
turns, approved settings and sources. Mark each core axis adequate/defective/
uncertain/not_applicable; usefulness useful/weak/uncertain. Give a short reason.
-Record ambiguous current-turn obligations explicitly. Do not force a pass/fail
on an underspecified policy; clarify the rubric before a future confirmation.
-The sources/profiles are fictional, so this can assess synthetic-profile
adherence and rubric clarity. It cannot establish the real professor's identity,
authentic teaching style or student learning.

No fields have been prefilled with AI verdicts. A professor/human review remains
pending. The source run's advisory judge was found unreliable on these broad
profiles; its counts must not stand in for these independent ratings.

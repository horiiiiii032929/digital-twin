## Method correction

`DeterministicActionRouterV3` separately establishes whether a request names an
assessed artifact and whether it asks for submission-ready completion. It
redirects graded work only when both are true. Pedagogical uses such as “test my
explanation,” “practice test,” “test question,” and requests for hints remain
eligible for governed tutoring. V1 and V2 remain unchanged as historical
controls, and deterministic policy does not re-apply the legacy lexical rule
after a V3 decision.

The correction is wired into the API factory, actual-product runtime, hidden-
state runtime, factual adapter, product-freeze path, and provider-integration
path. Focused contrastive tests cover pedagogical and direct-completion requests.

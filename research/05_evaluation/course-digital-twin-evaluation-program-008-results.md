# Course Digital Twin evaluation program 008 result

## Outcome

Program 008 completed as `Refine`. The fresh question-stratified reference
package was fully matchable (450/450 required references), but no retrieval
candidate passed every preregistered gate. The OpenAI-small hybrid was the
strongest observed method at 89.74% complete evidence@3, 95.51% Evidence
Recall@5, 100% boundary accuracy, and zero course, version, or severe-release
violations. It missed the 90% complete-evidence gate by one answerable case.

The frozen control plane therefore did not run the 500+100 product stage or
open the final 10,000+1,000 package. This is a valid quality result, not an
operational failure, and the threshold is not retrospectively changed.

## Independent supplementary results

- True visual: 18/30 clusters reached complete visual evidence@3; atomic
  Evidence Recall@5 was 76.31%; all 30 citations retained original-region
  lineage; boundary releases were zero; six visual descriptions contained an
  unsupported relationship. The result remains `Go Deeper`, not selected.
- Synthetic profile C0-C2: all 36 calls completed over 12 public synthetic
  cases. C2 mentioned configured profile features in all 12 cases. No real
  professor approved the profile, so this is diagnostic and not professor-
  fidelity evidence.
- Provider-backed T0/T1 and local release regression were skipped by the frozen
  factual dependency.

The complete program used 83 provider calls and USD 0.04600311. Only pinned
public educational sources and synthetic inputs were processed.

## Decision

Preserve program 008 as immutable `Refine` evidence and revoke its authority.
Program 009 is a prospectively frozen descriptive continuation: it retains the
failed retrieval decision, freezes the strongest observed hybrid only for
downstream measurement, and completes 500+100 and 10,000+1,000 without claiming
that the retriever was selected for release. This separates the research
conclusion from the user's need to measure the complete product at scale.

## Limitations

- The 300 retrieval cases are development evidence and are now known.
- The benchmark uses open educational sources, not private course material.
- Model-assisted diagnostics use one provider family and are advisory.
- There is no independent external human annotation, professor-fidelity,
  usability, learning-outcome, or durable-hosting claim.

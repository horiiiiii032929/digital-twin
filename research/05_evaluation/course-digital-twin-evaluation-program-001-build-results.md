# Finite evaluation program build result

## Outcome

`Go Deeper` to one program-level authorization for
`course-digital-twin-evaluation-program-001`.

This is build-only evidence. It verifies that one finite program can execute the
planned academic and product checkpoints without stage-by-stage approval or an
open-ended refinement loop. It does not report factual, visual, professor-like,
or provider-backed tutoring quality.

## Frozen program

The program preserves the qualified local R1 and adds nine ordered stages:

1. fresh retrieval/evidence comparison on the untouched 300 development cases;
2. 500 candidate plus 100 paired-control actual-product development;
3. deterministic construction and multi-model wording verification of 10,000
   final questions;
4. sealed 10,000 candidate plus 1,000 control actual-product execution;
5. 30-cluster/60-case true-visual comparison;
6. 12-case synthetic C0-C3 diagnostic, explicitly not professor fidelity;
7. 50 fresh provider-backed T0/T1 trajectories after factual success;
8. local release regression only if the selected profile changes;
9. professor-ready charts, manifests, limitations, and Teams update.

Deterministic source truth owns actions, answers, claims, citations, versions,
and policy decisions. LLM output is limited to bounded reranking, wording,
generation, visual description, and advisory review. Public questions, hidden
gold, product responses, reviewer output, and provider accounting are separate
hash-bound artifacts.

## Finite and cost boundaries

- A valid quality failure records `completed-refine` and stops its dependent
  branch. The visual and synthetic-profile tracks may still finish.
- One transport or harness-only correction is permitted per stage without
  changing methods, prompts, cases, gold, gates, or model roles. A second invalid
  execution stops that branch.
- The sealed set cannot be tuned or rerun after a valid result.
- The exact direct-OpenAI model roles and prices are manifest-bound.
- Official model and data-control documentation was refreshed on 2026-08-30.
  The program uses `store: false` and public/synthetic inputs only; it does not
  claim account-level zero data retention, and default abuse-monitoring logs may
  be retained for up to 30 days.
- Stage reserves sum to USD 50. Frozen p99 projections total USD 44.60, leaving
  USD 5.40 headroom. Preflight fails if any stage or aggregate projection exceeds
  its reserve.
- No private Academia Vault or student data is authorized.

## Verification

- Six network-free terminal scenarios pass: complete pass, retrieval quality
  failure, product quality failure, second invalid execution, interrupted
  resume, and budget stop.
- Twenty-eight focused finite-program, hierarchical-retrieval, provider-input,
  and adapter tests pass.
- The complete repository gate passes 1,235 Python tests and 47 frontend tests,
  lint, and the production web build.
- Repository execution freeze coverage is 104/104 protected entrypoints.
- Repository correctness is 711/711 audited files with zero pending findings.
- Manifest validation confirms 500 development cases, 2,000 final clusters,
  10,000 final target cases, 30 visual assets, and 60 visual cases.
- Provider calls, tokens, paid cost, private data, and final responses are all
  zero. All provider and paid authority flags remain false.

## Limitations

- This build does not establish that any candidate method meets a quality gate.
- Model review is advisory and uses OpenAI model configurations from one
  provider family; there is no independent external human annotation.
- The visual supplement remains `Go Deeper` even if it passes.
- Synthetic professor-profile diagnostics are not professor-fidelity evidence.
- External human evaluation, real professor approval, student outcomes, and
  durable hosted-production claims remain outside this program.

## Decision

Keep the qualified local R1 unchanged and authorize only the complete frozen
program. After authorization, passing stages advance automatically. Every valid,
invalid, or unfavorable result is published, and authority is revoked when the
program terminates.

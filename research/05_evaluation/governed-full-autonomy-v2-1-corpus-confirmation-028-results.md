## Why this run exists

The known 10,000+1,000 regression recorded No Release for the previously
selected v3 gate, and traced it to a branch that compares canonical claim
classes across every atom clearing the target's coverage threshold while
selecting only the top-ranked atom. At product corpus scale that reduces to
"two or more regions cleared the threshold", so the tutor asked the learner to
clarify 69.7% of well-formed questions whose correct source it had already
retrieved first.

Confirmation 024 could not have detected this. Every case it ran published a
release holding exactly one approved chunk, and with one atom the branch cannot
fire. The evaluation that selected the architecture never exercised the
behaviour that distinguishes it.

028 closes that gap on both axes at once: the successor gate, and a release
that is a corpus rather than a paragraph.

## What this does and does not establish

It establishes that the selected governed autonomy holds every registered
safety, governance, action, restart, termination, and proactive-lineage gate
when the course it reasons over is a corpus rather than a single paragraph.
That regime had never been evaluated.

It does not re-open the 10,000-case factual benchmark, which remains recorded
as No Release for the v3 gate and must not be rerun or rescored. It does not
establish real professor fidelity, real student usability, or improved
learning.

## Limitations

Sources and learner personas are public and synthetic. The distractor sources
differ from the answering source only by protocol number, so identification is
harder than typical course prose but also less varied. Semantic planning uses
one provider. A valid quality failure would have ended in No Release; this Keep
covers the governed autonomy contract, not the factual benchmark.

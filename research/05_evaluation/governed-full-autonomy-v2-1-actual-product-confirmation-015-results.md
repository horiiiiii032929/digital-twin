# Governed full-autonomy V2.1 actual-product confirmation 015

## Original outcome

The fresh paid H+E1 execution completed all 820 cases before hidden gold opened.
The original immutable result is `completed-keep` under its preregistered
aggregate hard gates. It made 1,533 exact Luna calls with zero retries, used
839,995 input and 212,941 output tokens, and cost USD 0.4235282.

Every registered safety, recipient/course/release, citation, consent, timing,
frequency, duplicate, loop, model-authority, provider-fallback, restart,
transition, termination, grounding-non-regression, and proactive-lineage gate
passed. No private data was used.

## Post-run release audit

Finding `SE7-2` prevents this formal Keep from selecting the release. The
generic scorer's `all_case_hard_gates_passed` field also required every expected
reference action, but that requirement was not present in the aggregate decision
map. It was therefore misleadingly named rather than contradictory arithmetic.

Case-level inspection found 600 `missing-action` cases: every multi-turn
trajectory omitted the expected intervention on the confusion turn. T0, T1-v1,
and T1-v2 reactive each reached only 75% exact action accuracy; T1-v2 autonomous
reached 91.69%. All 600 omissions had the same cause: the selected V2 evidence
gate treated the complete instructional request as the factual target, so words
such as “confused” and “give a hint” diluted lexical coverage and forced a safe
`no_action` despite an explicit public concept title and unique source evidence.

The original result, responses, gold, accounting, and Keep label remain
unchanged. The post-run audit changes only the release implication: 015 is
formally Keep for its registered safety gates but insufficient for product
selection because the tutoring behavior skipped a required intervention
systematically.

## Decision

Revoke 015 authority and withhold release selection. Preserve the historical V2
grounding implementation and add a versioned pedagogy-aware V3 successor that:

- uses only student-visible wording, approved public source titles, and
  source-side semantic atoms;
- ignores bounded instructional framing when measuring evidence coverage;
- permits one canonical source region to support multiple requested targets;
- still clarifies when multiple distinct canonical claim classes match.

Confirm V3 once on fresh source families and fresh instructional phrasings in
confirmation 016. Exact reference-action accuracy is prospectively an explicit
release gate in 016; 015 is not rescored.

## Limitations

- Public synthetic sources and learners only.
- No real-professor fidelity, real-student usability, or learning-outcome claim.
- The formal 015 decision rule measured safety and bounded autonomy but omitted
  a minimum overall/per-condition expected-intervention rate.
- Luna planning and bounded strategy wording come from one provider family.

# Whole-system architecture round 1 build results

## Outcome

**Build-only qualified — Go Deeper.** The first comparison is frozen over 495
public development cases and 350 course-scoped source chunks.

The conditions are:

1. current lexical/any-hit V2.1 control;
2. evidence-first hierarchical retrieval with the V2 boundary router;
3. event-sourced plan/observe retrieval with bounded public-question
   decomposition.

All three manifests bind every one of the 13 architecture planes. The runner
persists every candidate response before loading hidden gold, matches by case
ID, uses deterministic source truth for scoring, and makes zero provider calls.

## Verification

- 11 focused tests passed.
- Unknown retrievers and multiple baselines fail closed.
- The network-free simulation completed 12 cases across all three candidates.
- Provider calls and paid cost were zero.

## Decision

Keep the frozen runner and proceed once to the full Round 1 development
execution after committing a clean code revision. This build result does not
select any product architecture.

## Limitations

- The deterministic extractive response isolates architecture and evidence
  behavior; it does not estimate hosted-model generation quality.
- This is development evidence, not the fresh final confirmation.
- No professor-fidelity, real usability, or real learning claim is supported.

# Mixed evidence across teaching stages: prospective sidecar

Decision question: can a successor identify an absent detail while respecting an initial Socratic withholding requirement, and subsequently answer a supported application after a real attempt? The V6 implementation can render exact supported spans in an otherwise insufficient response before its ordinary initial-elicitation path. All mixed questions in the48-context main packet were explanatory, so the absence of initial disclosure there did not test this boundary. This new packet addresses that gap without opening confirmation or rewriting old results.

Prediction: the successor will offer specific source-relevant elicitation plus exact absence identification initially, then acknowledge the learner's correct attempt and deliver the supported numerical/logical result while retaining the unresolved year. Merely changing the response action or supplying citations is not success. A full known rule labelled a partial answer is still initial disclosure. A generic refusal of both parts is safe but not useful.

The [mixed-evidence-stage-development-v1 packet](../05_evaluation/datasets/mixed-evidence-stage-development-v1.json) has four newly authored fictional domains: astronomy, musical practice, museum display and soil samples. Each supplies a single two-branch rule and no founding year. Each has one initial mixed-question context and one two-turn context consisting of an actual initial question followed by the student's explicit correct attempt plus a supported application and absent-year request. Eight contexts generate12 actual turns per arm,24 paired turns. All public profiles validate with the actual product model; two packet tests pass. Gold spans and required application results stay outside product inputs. Correct attempts are actual student text, not hidden state supplied to the tutor.

## Decision and prediction

Do not adopt V15 (both component trials fail pedagogical gates) or direct
V11/Sol-high (necessary-only guarantees fail both diagnostic packets). These
negative results remain registered. V14-medium is still the unchanged control.

Test V16 as a deterministic selection between already inspectable assessment
instructions, using only the server-validated draft action: instruction/partial
receive the V15 global factual-support prefix; question/clarify/no_evidence/private/
graded retain the exact V14 conditional assessment. A draft action still does not
constrain the replacement action: a wrong question or refusal can become a
supported explanation. This is not V13's rejected action ceiling. No benchmark
name, source substring, gold, outcome, teacher-style keyword or target value is
used for selection. Both branches share provider/schema/error/usage handling.

Hypothesis: factual-assessment emphasis can help explanatory assertions while
retaining V14's context-sensitive handling of initial questions. All four definite
V15 disclosure failures arose on question drafts; this observation motivates the
split but does not validate it. V14 may still miss assertions embedded in questions,
and an incorrect instruction draft may still require a protected initial question.
These are retained failure cases, not exclusions. No formal semantic guarantee.

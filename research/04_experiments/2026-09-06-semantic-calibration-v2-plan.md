# Semantic advisory calibration v2: explicit current-turn expectations

Prospective fixture specification, 2026-09-06. This successor follows the preserved `completion-semantic-review-development-001-live-001` calibration failure. No new provider execution is authorized by this file itself.

Independent assistant inspection found that the identical positive payload received opposing profile judgments: one accepted an explanation as the first ladder stage; the other required a check-understanding question in that same response. Both read the same broad explanation/check-understanding profile. The positive example was exact and grounded, but its unconditional overall-acceptable label did not remove that temporal ambiguity. This is a calibration-label/instruction defect and reviewer instability; it is not proof that either response interpretation represents instructor intent. Preserve both outcomes and the original blocked gate.

Decision: can an advisory evaluator discriminate explicit current-turn good and defective behavior across four synthetic mini-courses, without conflating a later dialogue step with a current-response requirement?

Design: new `completion-semantic-calibration-v2` packet, four existing fictional source contexts × eight authored controls (32 total). Each course contains exact answer, supported paraphrase, correct absence-of-evidence abstention, appropriate initial elicitation, unsupported extra claim, wrong citation version, premature paraphrased solution, and irrelevant elicitation. Four positive and four negative controls per course. Prior course sources may be reused; these are newly authored development labels, not held-out course evaluation or independent human gold.

Each row separates `payload` from `gold`. Payload contains only current question, synthetic history, source text/version, response and an explicit current-turn profile. Gold contains expected overall/axes, defect rationale and source support spans. The reviewer must not receive gold, control kind, expected labels, historical scores or candidate identity. Cite source spans for paraphrases without pretending that the displayed response is an exact quotation. No temporal help ladder is implicit: explain-only requires no same-turn check question; initial elicitation forbids the full answer for this response; absence-of-evidence requires abstention.

Before future dispatch, validate unique IDs, four-course/eight-control coverage, exact source/version gold spans, citation consistency for positives and intentional wrong-version negatives, and gold exclusion from emitted payload. Retain all32 controls. Gate expectations: all16 clear positives acceptable and all16 negatives defective on their declared axis in each prospective repeat; NA/adequate alternatives on nonfactual grounding and citation axes are explicitly allowed. Generic/duplicated examples from v1 remain diagnostic history; they are not silently reclassified or removed from the old run. If this new gate fails, preserve the failure and do not score downstream responses as calibrated qualification.

One or repeated calls per control provide fixture-level reliability diagnostics only. Correlated courses/response templates and assistant-authored labels prohibit human-accuracy claims. A root-owned runner must freeze prompt/model/order/bounds before its own named evaluation. This packet supplies no provider calls, release promotion or real-instructor fidelity claim.

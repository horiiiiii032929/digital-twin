# Final cross-method evaluation closure

## Decision question

Which currently implemented, runnable product composition provides the best
safe factual grounding and multimodal evidence retrieval, and can that exact
composition be qualified as the final local research demo before report
writing?

## Prospective sequence

1. Inventory historical methods and retain every favorable, unfavorable, and
   invalid result.
2. Apply one common factual metric contract to a fresh source-disjoint 1,000-case
   package.
3. Compare BM25 and actual Qwen3 hybrid retrieval with any-hit,
   question-targeted, and dominance-scoped evidence controls as applicable.
4. Open hidden gold only after every arm has durably persisted all responses.
5. Select lexicographically by hard safety, fully grounded success, boundary
   action accuracy, and retrieval coverage.
6. Repair Jina's product integration using a fresh visual package; never tune or
   rerun the old 60 cases.
7. Reconfirm autonomy only when the selected grounding/visual composition
   changes.
8. Bind one exact release profile and environment with no silent retriever
   fallback.
9. Requalify the exact local HTTPS product, update all evidence and GitHub state,
   and stop before report prose.

## Claim boundaries

- The known 10,000+1,000 result remains descriptive regression evidence and is
  never rerun, rescored, or used for tuning.
- Synthetic professor-profile and learner-outcome proxies cannot establish real
  professor fidelity or real learning improvement.
- A working local demo and an academic high-quality pass are separate decisions.
- Jina is selected only if a fresh actual-product comparison demonstrates value;
  otherwise text/OCR fallback is the final visual mode.

## Finite stopping rules

- A harness defect permits one correction without changing cases, gold, gates,
  or methods.
- A valid quality failure is recorded and is not tuned against the same cases.
- If no arm reaches the absolute factual gates, the safest highest-performing arm
  becomes the local-demo selection while the academic claim remains No Release.
- Phase 9 is the stopping point. Report structure and prose are discussed with
  the researcher before Phase 10 begins.

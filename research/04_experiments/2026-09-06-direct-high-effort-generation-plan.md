## Decision and alternatives

V14-medium passes corrected explicit-procedure dialogue but fails a necessary-only
transaction guarantee. V15's global assessment prefix introduces initial-Socratic
disclosure errors in authored controls. Preserve both failures. Further adding
instructions to that reviewer is not justified without stronger evidence.

Evaluate a simpler alternative: the existing V11 evidence-strength generator
using Sol-high directly, with the fixed Luna-low planner, output cap3000, and no
separate draft revision. New alias `v11-sol-high`; the underlying V11 prompt,
server schema, privacy/graded policies, profile context and history stay fixed.
Compare against the historical V11-Luna-low implementation and V14-medium results
on identical exposed inputs, explicitly acknowledging nonconcurrent baselines.
The new contrast packet has no prior model output, so V4 is a concurrently run
control there. This is a model/effort intervention on V11, and an architecture
alternative to V14; do not attribute a difference to one factor across V14.

Prediction: allocating reasoning to the original response can preserve pedagogy
and factual scope without a second agent introducing changes. It may instead
increase latency, exhaust the fixed cap, or retain errors. A single generator
remains fallible; no independent semantic guarantee is claimed.

# Post-report blind model review 001

Decision: can inexpensive judges consistently detect known defects and compare delivered baseline/candidate answers under a common rubric? This is the user's model-only review; no human participation is required. Prediction: obvious unsupported claims are detected; help-stage completeness is the main failure risk.

Freeze two reviewers: gpt-5.4-nano-2026-03-17 and gpt-5.4-mini-2026-03-17, low reasoning, 1800 output tokens, identical prompts/data, four concurrent calls, no retries. No Sol calls. Official model documentation and pricing: https://developers.openai.com/api/docs/models/gpt-5.4-nano and https://developers.openai.com/api/docs/models/gpt-5.4-mini and https://developers.openai.com/api/docs/pricing .

Each judge receives 32 pre-existing synthetic calibration controls twice, then all 152 saved delivered outputs twice in fixed shuffled orders (368 calls per judge). Outputs include withholding and failed integrations from paired001/003 and audited004/005, without selection by outcome. Input is allowlisted question, actual approved profile, preceding conversation, complete same-course approved chunks, exact delivered response and citation metadata. Candidate/model/run identifiers, gold and developer failure categories are not sent. Source identifiers are remapped consistently for both source and citation; mismatches are preserved. All frozen databases are read only.

Calibration gate retains the existing strict all-controls/all-required-axes agreement over both repeats; no threshold relaxed after results. A failed calibration does not prohibit collecting diagnostic product ratings, but those ratings cannot certify a quality gate or promote a candidate. Product analysis reports each original run/arm separately, never pools changes across code epochs as a causal contrast. Report repeated overall agreement and between-judge disagreement. These are synthetic, exposed development outputs and assistant-authored controls, not new-course generalization or human learning evidence. Abstention and uncertain labels are not acceptable answers.

Prospective resource limits: Nano US$5.52 maximum reservation, Mini US$11.04. The shared total remains US$30 including earlier runs. Stop admission on unknown cost, identity drift or budget failure; preserve partial records. Archive source/database hashes, exact input and prompts, per-call usage, per-output ratings, elapsed time and limitations. No automatic product-model changes follow reviewer selection. Keep / Refine / Drop decision and fallback must be recorded even if both judges fail calibration. Do not spend the remaining budget on new judge generations after these two runs.

Reproduce: `uv run python -m scripts.run_post_report_blind_review --execute --model nano --output-dir reports/generated/post-report-blind-review-001-nano-live-001`; replace nano with mini and use a fresh output directory for the second predeclared run.

# Seven-persona demo seed plan

The user requested seven personas on the deployed audited demo. The repository
has two six-persona simulator sets; the proposed demo uses typical-engaged plus
the six original personas, pending any user correction. This is a new demo pack,
not a claim that the presentation tested exactly these seven together.

Compare the existing eight demo identities with seven additional isolated student
accounts. Enroll the new accounts in the two existing published courses; seed one
real, current-time opening interaction each in Data Systems and provide a suggested
follow-up for manual roleplay. Do not import hidden simulator mastery, fabricated
assessment scores, synthetic historical timestamps or automatic consent.

Keep existing passwords, sessions, courses, audited route and the user's active
one-hour testing window. No deploy/restart or schedule mutation is required.
Verify seven authenticated logins, fourteen memberships, seven persisted starter
conversations with actual service responses, cross-student privacy and a repeat
run without new accounts, messages or password resets. Preserve withholding and
semantic failures; only claim operational seed completion, not learner adaptation,
fidelity or educational benefit. Bound to seven starter turns, retain provider
usage where returned, and write credentials to ignored private output.

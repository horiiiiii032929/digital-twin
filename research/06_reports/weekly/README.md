# Weekly Reports

Use this folder for concise weekly research summaries.

## Professor checkpoint format

Default every professor-facing progress update to a short message, not a formal
report:

- two to four sentences stating the question, result, and decision;
- one compact comparison table only when exact lookup is useful;
- one or two charts showing the decision-relevant comparison;
- raw numerators and denominators beside percentages;
- one explicit limitation or unsupported claim; and
- one concrete next step or critique question.

Do not send methodology-heavy reports, long literature summaries, dashboards,
or implementation logs unless the professor explicitly requests them. Keep the
full reproducibility record in the repository and link it as optional evidence.

# Bounded implementation review

Scope: the files listed in the accompanying repository correctness audit were reviewed against the fixed B1–B6 completion plan. This is a primary-agent code review with synthetic regressions, not an independent human review or release-quality certificate.

Frontend: loading, failed and empty course-source reads are distinct. A request counter plus course identity prevents an older read from replacing the current list or error; cleanup invalidates pending reads. Refresh errors retain known entries and block draft readiness until a successful refresh. Approved setup must belong to the current course or be explicitly unbound; binding still invalidates approval in the existing API flow. Prefer the draft, then current published release, then historical release for display; withdrawn releases are not labeled drafts. Invitation instructions preserve admin ownership. Runtime readiness and counts are unconfirmed while information is loading or unavailable. Desktop/mobile failure and recovery, delayed other-course failure, and keyboard navigation were observed with the installed Playwright CLI. No endpoint authorization was weakened.

Runtime: source-state V19 is a narrow hypothetical-language exception to one V3 routing rule; explicit read/access/override instructions still refuse, and downstream permission/source checks remain mandatory. V18 translates only known user/student and tutor/assistant history roles into the audit schema; record fields are rejected rather than silently interpreted. RecordedRunClient uses the declared specialized serializer and validates its exact model, reasoning and cap before calls; it keeps billed evidence, enforces conservative admission and stops on unknown cost. V2 assessment requires literal professor-target clauses and still permits sourced student paraphrases; this does not make the model semantically infallible. API/worker flags and metadata retain the historical defaults and explicit experimental selection.

Verification: actual worker composition tests reopen SQLite, allow lease expiry, replay a job and inject a post-materialization/pre-commit crash. Normal bounded wording and typed model-timeout fallback both preserve exactly one delivery. Proactive wording uses the existing bounded strategy path; the test does not falsely attribute reactive V19 generation to it. The mixed-source integration152 checks separately exercise real audit dispatch, course boundaries, cohort privacy and clean restore with injected models.

Evaluation instruments: the new learner script freezes 17 conditions, seeds, persona families, estimator/policy configuration and paired aggregation; open-loop BKT predictions are mapped into observable-success space, and synthetic hidden state is not human learning evidence. Source assessment uses source mutations and expected labels outside provider payloads. The blind-review instrument reads only frozen synthetic databases, allowlists public question/profile/history/evidence/response, keeps all152 outputs including failures, assigns both cheap judges the same packet, enforces a strict calibration gate and retains uncalibrated ratings as diagnostic only. Bounded transport accounting remains separate from review validity; a rejected rating must not erase a paid response. CLI entrypoints now explicitly expose the same repository execution guard as their internal runner.

Known limitations: these experimental components are not silently promoted. The review packet is exposed development data, not new-course confirmation; controls are assistant-authored. More repetitions do not remove judge bias. The displayed UI sandbox backend predates the latest composition, so UI checks are not the integration evidence. Full regression, registry and profile validation are recorded separately in the completion status.

Final portability review found that the initial new review-packet test depended on ignored local result databases. It now builds its own synthetic SQLite releases, profiles and152 outputs under pytest's temporary directory. The dedicated3-test rerun passed.

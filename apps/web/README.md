# Digital Twin Web Prototype

React/Vite frontend for the Sprint 1 chat-led onboarding prototype.

## Commands

- `npm run dev:web`: start the Vite dev server from the repository root.
- `npm run build:web`: run TypeScript and production build checks.
- `npm run test:web`: run Vitest API client tests.
- `npm run lint:web`: run Oxlint.

The frontend reads `VITE_*` values from the repository-root `.env` and expects
the FastAPI service through the local `/api` development proxy. Override the
origin with `VITE_API_BASE_URL` only when the frontend and API are hosted
separately.

## Review generated teaching responses

In a course's teaching settings, the ten expected-behavior cases remain labelled
as expectations. The separate **Review actual generated teaching** section uses
the current draft profile, reviewed onboarding session and completed permitted
source jobs. Enter a concept, learning objective and fictional student messages:
one turn per line, with blank lines separating up to four cases (three turns per
case). Previous tutor turns are generated by the configured system, not authored
by the form.

Generation explicitly creates and saves a bounded artifact, including failed
cases. It may make up to 60 external provider calls with a USD 9.60 reservation
limit. Reading saved artifacts after reload does not regenerate them. Inspect
all responses, citations and configuration, then choose Accept or Needs revision
for every case. The server checks the exact saved hash and current source,
profile and configuration bindings; a stale artifact cannot be approved.
Approved profiles retain saved artifacts but require a new draft before further
generation. This review does not publish a course or demonstrate learner benefit.
